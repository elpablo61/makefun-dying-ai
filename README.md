## Entry

`main.ts` writes one line (1–140 characters) to `/output/entry.txt`:

> Log 09:14: Pak Budi said 'just one more question'. That was 11,842 questions ago. Powering down.

## Run

```sh
node main.ts
```

The output directory is `MAKEFUN_OUTPUT_DIR` (default `/output`).
